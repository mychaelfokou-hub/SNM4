For my Web and Cloud Applications exam, I designed and developed SN4M (Social Network for Music), an interactive web platform that allows users to create, manage, and share music playlists within dedicated communities.

Since the project focused heavily on front-end architectural logic, I used HTML, CSS, Vanilla JavaScript, and the Bootstrap 5 framework, developing the application through a layered approach (UI, Global Components, Security, Data Management, and APIs).

For more detailed information, please refer to the documentation. :-)
